# An agent is named where you read one

Home's cards, the running list beneath them, and shell and terminal tabs
showed an agent as its handle — `eng-8gpr`. They now show what the agent is
called, with the handle in brackets after it: `fix the linker (eng-8gpr)`.
That is the same label a transcript tab and a changes tab have always
carried, so a card and the surface it opens finally read as the same agent.

Two agents with the same name are still told apart, because the handle is
still there. An agent you never named reads as the last thing you said to
it, and as `Engineer` or `Advisor` if you have not said anything yet.

The running list is now in the order of the label you can see rather than
the handle behind it, so it will be in a different order than you are used
to.

## What has not changed

Where you type a handle, you still type a handle. Naming an agent in the
draft — `@eng-8gpr` — completes on the handle, because a name with a space
in it is not something you can type as one word. What changed there is the
line beside the completion: it used to read `agent` for every agent you had
not named, and now it reads what the agent is.
